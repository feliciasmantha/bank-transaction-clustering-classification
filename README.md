# Bank Transaction Clustering & Classification

Machine learning project from the Dicoding submission, exploring bank transaction patterns through clustering and classification.

### Methods
- K-Means Clustering, PCA, and Silhouette Score
- Decision Tree and Random Forest Classification
- Hyperparameter tuning using GridSearchCV and RandomizedSearchCV

### Tools
Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Yellowbrick, Joblib.

### Note
The classification models predict cluster-based labels, not actual fraudulent transactions.
